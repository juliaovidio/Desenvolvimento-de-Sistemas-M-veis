## Requisitos Funcionais do Sistema

### RF01 – Permissão de localidade:
O sistema deve pergunatr se o usuario permiti que ele utilize sua localização.

### RF02 – Compartilhamento de Conteúdo:
O sistema deve permitir que o usuário compartilhe informações da sua localidazação para o gerente quando apertar o botão de atualizar. 

### RF03 – Histórico de Atividades:
O sistema deve registrar e permitir que o usuário visualize um histórico detalhado de todas as informações do seu trabalho(trajeto) que irá realizar.

### RF04 – Cadastro de Motorista:
O sistema deve permitir o cadastro de motoristas com nome e status.

### RF05 – Cadastro de Veículo:
O sistema deve permitir o cadastro de veículos com placa e status.

### RF06 – Associação de Veículo ao Motorista:
O sistema deve permitir vincular um veículo a um motorista antes do início da rota.

### RF07 – Criação de Rotas:
O sistema deve permitir ao gerente cadastrar e disponibilizar rotas para execução.

### RF08 – Início de Rota:
O sistema deve permitir que o motorista inicie uma rota atribuída.

### RF09 – Atualização de Localização:
O sistema deve permitir que o motorista atualize manualmente sua localização durante a rota.

### RF10 – Visualização de Rotas pelo Gerente:
O sistema deve permitir que o gerente visualize o status e progresso das rotas em andamento.

### RF11 – Registro de Entregas:
O sistema deve permitir registrar entregas vinculadas a uma rota.

### RF12 – Confirmação de Entrega:
O sistema deve permitir que o motorista confirme a realização de uma entrega.

### RF13 – Registro de Histórico:
O sistema deve registrar automaticamente eventos importantes da rota no histórico.
