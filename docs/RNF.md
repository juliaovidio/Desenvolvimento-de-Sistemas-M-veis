## Requisitos não funcionais do sistema

 ### RNF01 – Segurança da Informação:
O sistema deve garantir a proteção dos dados dos usuários (motoristas e gerentes), utilizando autenticação segura e criptografia das informações de login, rotas e localizações.

### RNF02 – Desempenho:
O sistema deve atualizar e exibir a localização do motorista em tempo real quando ele aperta o botão ou com quando entra no aplicativo.

### RNF03 – Disponibilidade:
O sistema deve estar disponível para acesso 24 horas por dia, 7 dias por semana, com no mínimo 99% de tempo de funcionamento mensal.

### RNF04 – Usabilidade:
O sistema deve possuir interface intuitiva e de fácil uso para motoristas e gerentes.

### RNF05 – Compatibilidade:
O sistema deve ser compatível com dispositivos móveis Android e iOS.

### RNF06 – Tempo de Resposta:
As ações do sistema devem responder em até 3 segundos em condições normais de uso.

### RNF07 – Escalabilidade:
O sistema deve suportar múltiplos motoristas e rotas simultaneamente sem perda de desempenho.

### RNF08 – Precisão de Localização:
O sistema deve utilizar GPS com precisão mínima aceitável para rastreamento (ex.: até 10 metros).

### RNF09 – Integridade dos Dados:
O sistema deve garantir que os dados armazenados não sejam corrompidos.

### RNF10 – Backup de Dados:
O sistema deve realizar backups periódicos das informações armazenadas.

### RNF11 – Auditabilidade:
O sistema deve permitir rastrear todas as ações realizadas pelos usuários.

### RNF12 – Consumo de Bateria:
O aplicativo deve otimizar o uso de GPS para reduzir o consumo de bateria do dispositivo.

### RNF13 – Segurança de Acesso:
O sistema deve possuir controle de acesso baseado em perfil (motorista e gerente).
